                                           Контрольные вопросы
1. Какие способы установки PHP существуют?
PHP можно установить несколькими способами.
Первый способ - скачать PHP с официального сайта, распаковать его и добавить путь к PHP в системную переменную Path.
Второй способ - использовать готовую среду разработки, например XAMPP, которая включает PHP и веб-сервер Apache, а также phpMyAdmin.
В данной лабораторной работе можно использовать любой из предложенных способов.
2. Как проверить, что PHP установлен и работает?
Для проверки установки PHP можно открыть командную строку и выполнить команду:
php -v
Если PHP установлен правильно, командная строка покажет версию установленного PHP.
Также работу PHP можно проверить через веб-сервер, создав файл index.php с кодом:
<?php

echo "Привет, мир!";
После запуска файла в браузере должно появиться сообщение:
Привет, мир!
3. Чем отличается оператор echo от print? 
echo и print используются для вывода данных на экран.
• print работает только с одним значением и возвращает число 1, что позволяет использовать его внутри выражений. 
• echo ничего не возвращает, но принимает несколько аргументов и работает чуть быстрее. 
• На практике. Подавляющее большинство разработчиков использует echo.
